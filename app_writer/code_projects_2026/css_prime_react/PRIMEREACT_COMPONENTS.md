# PrimeFlex - Utility-First CSS Library

**Version**: 3.x / 4.x  
**Type**: CSS Utility Library  
**Official Documentation**: https://primeflex.org/

---

## OVERVIEW

PrimeFlex is a lightweight CSS utility library that provides:
- **Grid System** - 12-column responsive grid
- **Flexbox Utilities** - Complete flexbox control
- **Spacing** - Margin and padding utilities
- **Display** - Display property utilities
- **Typography** - Text alignment, wrapping, transformation
- **Elevation** - Shadow utilities
- **Form Layout** - Form-specific utilities
- **Responsive Design** - Mobile-first breakpoints

---

## INSTALLATION

```bash
# Using npm
npm install primeflex

# Using yarn
yarn add primeflex

# Using pnpm
pnpm add primeflex
```

### Import

```javascript
// In your main file
import 'primeflex/primeflex.css';
```

### CDN

```html
<link rel="stylesheet" href="https://unpkg.com/primeflex@latest/primeflex.css">
```

## GRID SYSTEM

### Basic Grid Classes

| Class | Description |
|-------|-------------|
| `grid` | Creates a flex grid container |
| `grid-nogutter` | Removes gutters from grid |
| `col` | Auto-width column |
| `col-fixed` | Fixed width column |
| `col-1` to `col-12` | Column width (1-12 units) |
| `col-offset-1` to `col-offset-12` | Column offset (left margin) |

### 12-Column Grid

```html
<!-- Equal width columns -->
<div class="grid">
    <div class="col">Column 1</div>
    <div class="col">Column 2</div>
    <div class="col">Column 3</div>
</div>

<!-- Specific width columns -->
<div class="grid">
    <div class="col-4">4 units</div>
    <div class="col-6">6 units</div>
    <div class="col-2">2 units</div>
</div>
```

### Responsive Grid

| Breakpoint | Prefix | Screen Size | Media Query |
|------------|--------|-------------|-------------|
| Small | `sm:` | Phones | min-width: 576px |
| Medium | `md:` | Tablets | min-width: 768px |
| Large | `lg:` | Notebooks | min-width: 992px |
| Extra Large | `xl:` | Monitors | min-width: 1200px |

```html
<!-- Responsive columns -->
<div class="grid">
    <div class="col-12 md:col-6 lg:col-3">Responsive Column</div>
    <div class="col-12 md:col-6 lg:col-3">Responsive Column</div>
    <div class="col-12 md:col-6 lg:col-3">Responsive Column</div>
    <div class="col-12 md:col-6 lg:col-3">Responsive Column</div>
</div>
```

### Grid Features

**Multiline**: Columns automatically wrap when exceeding 12 units
**Nested**: Grids can be nested inside columns
**Offset**: Use `col-offset-{n}` for left margin spacing
**Fixed Width**: Use `col-fixed` with inline width style

## SPACING UTILITIES

### Format
`{property}{side}-{size}` or `{property}{side}-{breakpoint}-{size}`

### Properties

| Prefix | Property |
|--------|----------|
| `m` | Margin |
| `p` | Padding |

### Sides

| Suffix | Side |
|--------|------|
| `t` | Top |
| `b` | Bottom |
| `l` | Left |
| `r` | Right |
| `x` | Left and Right |
| `y` | Top and Bottom |
| *(none)* | All sides |

### Sizes

| Size | Value | Calculation |
|------|-------|-------------|
| `0` | 0 | $spacer * 0 |
| `1` | 0.25rem | $spacer * 0.25 |
| `2` | 0.5rem | $spacer * 0.5 |
| `3` | 1rem | $spacer * 1 |
| `4` | 1.5rem | $spacer * 1.5 |
| `5` | 2rem | $spacer * 2 |
| `6` | 3rem | $spacer * 3 |
| `auto` | auto | Auto margin (margins only) |

### Examples

```html
<!-- Margin examples -->
<div class="m-2">Margin all sides (0.5rem)</div>
<div class="mt-4">Margin top (1.5rem)</div>
<div class="mb-3">Margin bottom (1rem)</div>
<div class="mx-auto">Auto horizontal margins (centering)</div>
<div class="my-2">Margin top and bottom (0.5rem)</div>

<!-- Padding examples -->
<div class="p-3">Padding all sides (1rem)</div>
<div class="pt-2">Padding top (0.5rem)</div>
<div class="px-4">Padding left and right (1.5rem)</div>

<!-- Responsive spacing -->
<div class="m-2 md:m-4 lg:m-6">Responsive margins</div>
<div class="p-1 sm:p-2 md:p-3 lg:p-4">Responsive padding</div>
```
