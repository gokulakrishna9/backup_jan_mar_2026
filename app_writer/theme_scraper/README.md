# Theme Scraper

Extracts design tokens (colors, typography, spacing, borders, shadows, component styles) from any website and produces a `react_theme.json` file compatible with the REAW pipeline.

## Requirements

```bash
py -m pip install playwright requests
py -m playwright install chromium
# Optional (better CSS parsing): py -m pip install tinycss2
```

## Usage

### Scrape and write to application_definitions/
```bash
py theme_scraper/scrape.py \
    --url https://example.com \
    --output <path_to_application_definitions>
```

### Scrape and print JSON to stdout
```bash
py theme_scraper/scrape.py --url https://example.com --pretty
```

### Show browser during scraping
```bash
py theme_scraper/scrape.py --url https://example.com --headed --verbose
```

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--url` | (required) | Target website URL |
| `--output` | None | Path to write `react_theme.json` (prints to stdout if omitted) |
| `--headed` | false | Show browser window |
| `--timeout` | 30000 | Page load timeout in ms |
| `--verbose` | false | Print extraction details |
| `--pretty` | false | Pretty-print JSON (always pretty when writing to file) |

## How It Works

1. **Scrape** (`scraper.py`) — Visits the URL in Chromium, extracts computed styles from key DOM elements (body, headings, buttons, inputs, nav, cards, tables, sidebar, links), downloads linked stylesheets, and reads CSS custom properties from `:root`.

2. **Parse** (`css_parser.py`) — Parses downloaded CSS to extract additional custom properties. Uses `tinycss2` if available, falls back to regex.

3. **Extract** (`token_extractor.py`) — Analyzes raw data to produce normalized design tokens. Colors are parsed to RGB, clustered by distance, and classified into semantic roles (accent, background, text, border, success, warning, error, info) using HSL hue analysis. Typography, spacing, borders, and shadows are extracted from computed styles.

4. **Map** (`theme_mapper.py`) — Fills in defaults for any missing tokens and structures the output to match the `ThemeDefinition` schema used by REAW Phase 2.

## Output

The output `react_theme.json` contains:
- `colorPalette` — 12 semantic color tokens
- `typography` — font family, sizes, weights, line height
- `spacing` — unit-based spacing scale
- `borders` — radius, width, color
- `shadows` — small/medium/large box shadows
- `components` — per-component overrides (button, input, card, table, sidebar)
- `animationStyle` — transition and interaction animation settings
- `source` — URL and timestamp of the scrape

## Integration with REAW

Drop the output into your `application_definitions/` folder (replacing the default `react_theme.json` generated by Phase 1), then run Phase 2 as normal:

```bash
# 1. Generate default definitions
py reaw/generate_react_app.py --input <schema.sql> --output <output_dir>

# 2. Scrape a theme and overwrite the default
py theme_scraper/scrape.py --url https://target-site.com --output <output_dir>/application_definitions

# 3. Regenerate React code (now uses scraped theme)
py reaw/phase2_generate_react_code.py --output <output_dir>
```
